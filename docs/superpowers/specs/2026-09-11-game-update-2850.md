## 리뷰 반영 (2026-09-11 저녁, `review-2850.md`)

RVA 재도출 리뷰 1차: 코드 상수 17개(1차 3 + 2차 14: specguard 7 + spawnguard 3 + 실행 지점 1 + 로스터 3) 전부 독립 실측과 일치 - 승인. 문서 정정 3건
(위 소제목·문장, 썽크 본체 0x0E0D44F0, `grant.h` 본체 주석)을 반영했다. 관찰 중 같이 반영한 것:

- 검사 썽크 가드를 E9 한 바이트에서 "E9 를 따라가 본체 프롤로그 11바이트 대조" 로 올렸다
  (`hire_check_jmp_target`·`hire_check_body_ok`, 시험 4개). 썽크 주변 ±0x200 의 E9 43개 중 이
  프롤로그로 가는 것은 하나뿐이다. 읽기 실패와 불일치를 로그에서 구분한다.
- `tools/rtti/cheat_report.py` `find_handler` 가 `rva_to_off` 실패 때 튜플 대신 `None` 을 돌려줘
  호출부에서 `TypeError` 로 죽던 것을 고쳤다(`return None, ''`).
- `companion.h` 소환 인자 첫째를 "문객체" 에서 용병단 컴포넌트 `[[액터+0x68]+0x110]` 로 정정
  (래퍼 0x2B7B270 `mov rcx,[rdi+0x68] / mov rcx,[rcx+0x110] / call` 디스어셈블로 확인).
- `grant.h` 한도 목록 오프셋(+0xF8·+0x100)은 2760 실측이라 2850 미확인으로 표시.

반영하지 않은 관찰: 본문 길이 3바이트 차이(int3 패딩 계수, 판단 무관). 데이터 전역은 런타임 로그
`소환 표 N개` 로 확정 예정.
