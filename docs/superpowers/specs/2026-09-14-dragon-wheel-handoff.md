# 스토리 탈것(드래곤·ATAG) 소환 — 핸드오프 (2026-09-14)

원본 스토리 탈것(드래곤 블랙스타, ATAG)을 얻지 않고 소환 바퀴에 올려
소환·탑승시키는 작업의 인계. 전체 조사는
`2026-09-12-summon-wheel-research.md` (§0~§9, 라이브 실측 1~9). 이 문서는
**다음 세션이 바로 이어갈 수 있게** 현 상태·재현 절차·남은 한 겹을 모은다.

## 1. 목표

스토리로만 얻는 드래곤·ATAG 를, 이미 가진 여분 동반자의 종을 바꿔
원본 없이 게임 소환 바퀴에서 소환·탑승. 원본 개체·스토리 진행 불필요.

## 2. 지금까지 규명·달성 (전부 `develop` 머지, PR #3)

- **소환 바퀴 = 부르기 메시지** `TrocTrCallSpecialVehicleByQuickSlotReq`
  (ID **2318**, 역직렬화 `0x2964B30`). 본문 21바이트
  `[u32 번호][float3 좌표][u32][u8]`, 첫 u32 = 번호 해시 키.
- **두 색인**: 번호 해시(전역 `0x6C2E300`, 종 교체 무관) + 종류별 색인
  (용병단 컴포넌트 `+0x48`버킷수/`+0x58`버킷표/`+0x60`슬롯, 종 교체가
  안 따라옴). 종류별 색인은 **명부 재구축(세이브-로드)으로 갱신**됨(실증).
- **소유자 필드 `+0x148` 무관**: 특수 탑승물(0xFFFF)도 바퀴에 뜬다.
- **부르기(2318)로 원본 없이 전용 슬롯 등록 성공**: 회색 빈 슬롯 →
  블랙스타/ATAG 아이콘. 슬롯 등록·클라 알림은 부르기 처리기가 **무조건**
  한다(`0x2ADBA00 @ 0x2AB9020` 리스트 append + `0xFB7F060` msg 0x3f5).
- **실제 스폰 게이트 `0x2ACA250`**: 부를 수 있는 탈것 타입 레지스트리에서
  종의 타입행을 찾는다. **라이브로 레지스트리에 드래곤(2)·ATAG(3,4)가 이미
  있음을 확인** → 스토리 게이트가 아니다(정적 판정 반증). 레지스트리 조작
  불필요.

## 3. 남은 한 겹 (다음 세션의 핵심)

**게이트는 통과해야 하는데, 부르기 구동 뒤 명부 레코드의 스폰 핸들
`+0x50` 이 안 붙는다(=실제 월드 스폰 안 됨).** 부르기 결과 코드는 0(성공),
슬롯 아이콘은 채워지는데, 개체가 안 나온다. 게임 UI 로 슬롯을 클릭해도
서버 메시지가 안 나가고(클라 로컬) 거부 문구 없이 반응 없음.

모순: 레지스트리에 드래곤(2)이 있으니 게이트(`0x2ACA250`)는 매칭→
`0x2ACA31A`→`0x2A22DE0`(실제 스폰) 로 가야 한다. 그런데 `+0x50`=0.

**갈라낼 것**:
1. 부르기 구동이 게이트(`0x2ACA250`)에 실제로 도달하는가, 도달 시 검색 키
   `bx`(= `word[CharacterInfo(종 rec+0x20)+0xBE]`)가 드래곤 타입행(2)이고
   매칭하는가 — **라이브 훅**(MinHook)으로 `0x2ACA250` 진입 시 `r9w`(bx)와
   반환 경로 로그. 사자(소환됨) vs 드래곤(안 됨) 대조.
2. 매칭하는데도 `0x2A22DE0`(0x580 스택, `CommonActor` 필드 스폰)이 종 교체
   드래곤에서 실패하는가 — 그 함수 안 좌표/collision/종 검사 분기. 단
   종 교체 드래곤이 **거점에 자동 스폰된 적이 있으니**(실측) 스폰 자체는
   가능 → 좌표/collision 유력.
3. 부르기 처리기(`0x2964B30`)가 슬롯 등록 뒤 게이트 경로로 안 가고 다른
   분기(알림만)로 빠지는가.

## 4. 재현 절차 (게임 실행 중, probe·명령 파일·python)

```
# 1) 여분(중복) 동반자를 드래곤/ATAG 종으로 교체
probe: setspecies <용병번호> 7008          # 드래곤 Riding_Dragon_1
       setspecies <용병번호> 6818          # ATAG Riding_WarMachine_Unique_1
# 2) 재구축 유발(종류별 색인 갱신) — 세이브-로드가 확실. 획득(2338)은 대상 필요
#    (드래곤 슬롯은 재구축 후에 아이콘이 떴다. ATAG 는 재구축 안 하면 안 뜸)
# 3) 부르기 구동 (좌표는 summon 2962 가 로그에 찍는 카메라 초점 재사용)
bin64/cdtoybox_cmd.txt <- summon <번호>     # 로그의 "좌표 (x,y,z)" 취함
   부르기 와이어 = 0E09 00 1500 + <u32 번호> + <float3 x,y,z> + 00000000 + 00
bin64/cdtoybox_cmd.txt <- msg <위 와이어 hex>
# 4) 스폰 여부 확인 (python ReadProcessMemory)
#    명부 레코드 +0x50 spawn_handle 이 0 이 아니면 실제 스폰됨
```

부르기 ID 2318 은 게임 재시작마다 로그 "메시지 TrocTrCallSpecialVehicle…
ID 2318" 로 확인. companion.cpp 해석 표(`kMessageClasses`)에 이미 추가됨.

## 5. 핵심 주소·사슬 (1.0.0.2850, 모듈 베이스 0x140000000)

| 대상 | RVA / 값 |
|---|---|
| 부르기 역직렬화 | `0x2964B30` (ID 2318) |
| 부르기 작업(번호 해시) | `0x2964B30`→`0x2AD3270`→`0x2AD9890`→`0x2ADBA00` |
| 슬롯 등록(무조건) | `0x2ADBA00 @ 0x2AB9020` |
| 클라 알림(무조건) | `0x2964DC8`→`0xFB7F060` (썽크 `0x26B14E0`), msg `0x3f5` |
| **실제 스폰 게이트** | **`0x2ACA250`** (r9w=검색 타입행) |
| 게이트 매칭→스폰 | `0x2ACA31A`→`0x2A22DE0` |
| 게이트 무매칭→성공0 | `0x2ACA2F8` `mov [rsi],0` |
| 번호 해시 전역 | `0x6C2E300` (= reg 헤더, cnt 28) |
| 소유 그룹 인덱스 배열 | 전역 `0x6C2DD88`→`[+0]`→`[+8]`→`[+0x2F8]`=reg→`reg+0xC0`begin/`+0xC8`count |
| 라이브 그룹(2026-09-14) | [24,25,26]; grp+0x58 타입행 배열/+0x60 개수 |
| 그룹 24/25/26 타입행 | [1,5] / **[3,4] ATAG** / **[2] 드래곤** |
| 그룹 getter | `0x382A30`(썽크)→`0x86F79B0`: hdr=[0x6C2E300], arr=[hdr+0x58], grp=[arr+idx*8] |

명부 레코드 필드: `+0x20`종(캐릭터 행)·`+0x22`0xFFFF·`+0x28`용병번호·
`+0x50`스폰핸들·`+0x148`소유자행. 용병단 컴포넌트: `+0x18`records·`+0x20`count.

## 6. 도구·주의

- **명부 주소는 휘발성**: 동반자 수가 바뀌면 컴포넌트·레코드 통째 재생성.
  쓰기 전 번호로 재조회(`resolve_species_write`/`setspecies`). 생 poke 금지.
- **라이브 모듈 데이터 전역**은 대부분 probe `dump` 로 안 읽혔으나(2850
  섹션), `0x6C2DD88`·`0x6C2E300` 계열은 python `ReadProcessMemory` 로
  읽혔다(위 사슬). TLS 선택(`gs:[0x58]+0x1ec`)은 python 으로 재현 불가하니
  전역 사슬을 직접 따라간다.
- **Semgrep 훅이 Edit 를 막는다**: Write 나 sed 치환으로 우회(`[[semgrep-hook-blocks-edit]]`).
- 종 교체 시험은 **여분(중복) 동반자**로. 스폰 시험은 소환 널 가드
  (`spawnguard.cpp`)가 있어야 안전.

## 7. 다음 실측 후보 (우선순위)

1. `0x2ACA250` MinHook → 부르기 구동 시 진입 여부 + `bx` 값 + 반환 경로.
   사자(1000414 등, 소환됨) vs 드래곤 대조로 게이트 매칭 유일성 확정.
2. 매칭인데 스폰 실패면 `0x2A22DE0` 안 좌표/collision 분기. 좌표를 플레이어
   실제 위치로 정확히 주고 재시도(거대 드래곤 collision).
3. `+0x50` 스폰 핸들이 붙으면 화면 확인(하늘 포함) — 드래곤은 "하늘에서
   날아와 자동 탑승"(사용자 공략), ATAG 는 마을·정착지 근처 호출 제한.
