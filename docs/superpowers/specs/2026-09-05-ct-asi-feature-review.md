# CT / ASI 참고 모드 기능 검토 — 우리 모드로 추출할 후보

> **정리 (2026-09-21) — 📐 설계 → 일부.** B-1 플레이어 치트(`STATUS.md` §1.13) · B-7
> 가방(§1.16) · B-9 Max Refine(§1.12 — 지금은 "전부 담금질 최대" · "전부 연마 최대" 둘)은
> 들어왔다. B-8 중 아이템 하나 지우기는 닫힌
> 길이다(`TROUBLESHOOTING.md` §9). B-5 텔레포트를 포함한 나머지는 구현 기록이 없다.
> "소켓은 게임이 막음" 은 틀렸고(`2026-09-07-socket-grant-unlock-research.md`), "캐릭터
> 스폰(우리 고유)" 은 금지·제거됐다(`TROUBLESHOOTING.md` §1.9).

**대상:** Nexus 3209 "Crimson Desert Enhanced Ultimate" = Cheat Engine 테이블(CT)
+ standalone trainer(ASI, `CrimsonInvEditor.asi`). 둘 다 같은 코드베이스, 게임
2.0.0.2(build 1.0.0.2692) 기준. 소켓·장비·텔레포트·염색 리버스의 원출처는
**XeTrinityz(=ReXooGen)/Trinity (MIT)**.

**핵심 전제:** 우리 CDToybox 는 **인프로세스 주입 DLL(ASI 급)**이다. CT(Cheat
Engine)가 "trainer only, needs a game thread pump" 이라고 못 박은 기능 — **라이브
염색, 없는 zone 생성, 빠른 이동** — 은 게임 스레드에서 함수를 부를 수 있어야
하는데, 우리는 이미 give/spawn 을 TLS 로 선 게임 스레드에서 실행한다. 즉 **CT 가
못 하는 것도 우리는 원리상 가능**하다. 이게 이 검토의 방향을 정한다.

## B. 추출 후보 — 高가치 · 인프로세스라 유리

1. **플레이어 치트 그룹** — Godmode, 무한 HP/스태미나/정신력, 이동·공격속도.
   ⚠ 참고 모드 실수 반복 금지: (a) status block 은 캐릭터별 다른 슬롯이다(Kliff
   고정 아님 — 컴포넌트 리스트로 찾아야 함). (b) Max Combat Stats/속도는 "아무
   액터"에서 닿는 스탯 컨테이너를 건드려 **주변 NPC까지 강화**됐다 → 반드시
   본인(cplayer)으로 제한.

2. **탈것(Mount) 그룹** — 무한 스태미나·비행, 무한 브레스(와이번/드래곤), 탈것
   선택. 우리는 이미 탈것을 Mercenary 로 등록·해석하니 연장선. 탈것 몸체 오판
   전례 있음(정확한 대상 선택 필요).

3. **시간 제어(Time)** — Freeze / Advance / Rewind / Set. 시계는 **코드 검색으로
   위치를 잡는다**(고정 주소 금지 — 참고 모드가 죽은 주소로 몇 버전간 조용히
   아무것도 안 한 전례). "0으로 채워진 블록을 자정으로 오인"하는 검증 버그도 회피.

4. **게임 속도** — 엔진 자체 time scaling 0.1~10x. 참고 모드 초기엔 상쇄되어
   아무 효과 없던 버그 → 엔진 경로를 정확히 써야.

5. **텔레포트 to 맵 마커** — 빨간 마커 찍고 점프. **월드 원점을 라이브로 읽어**
   캘리브레이션(고정 주소로 하면 패치에 깨짐; 지역마다 map↔world 변환이 달라
   단일 측정은 틀림 → 원점 상대로 보정). 출처 ReXooGen/Trinity MIT.

6. **내구도** — Keep at 100(사용/장착 시 수리) / No Durability Loss(현 상태 동결)
   / Repair. 둘은 같은 명령을 소유하므로 서로 배타. "durability write 는 건너뛰고
   그 뒤 clamp-to-zero 분기는 안 건너뛰어 0으로 만든" 버그 회피.

7. **가방 슬롯 편집** — 현재/최대/총 슬롯 보기·편집, 999 원클릭, 세션 유지.

8. **아이템 복제/삭제** — 복제는 사본마다 새 identity(안 그러면 두 슬롯이 같은
   객체를 주장해 게임이 해석 실패). both copies 에 씀(리로드 생존). 빈 슬롯 필요.

9. **Max Refine 일괄** — 착용 장비 전부 한 번에 최대 연마(연마 불가 항목은 건너뜀).
   우리 equip 에디터에 붙이기 쉬움.

10. **라이브 염색 업그레이드** — ASI 는 "Dye applies live, 재장착 불필요" +
    "없는 zone 을 Apply 로 생성"까지 한다(둘 다 게임 스레드 필요 → 우리 가능).
    지금 우리 dye 는 메모리 쓰기 + 재장착(CT 급). 엔진의 dye 갱신 함수를 찾아
    게임 스레드로 부르면 우리도 라이브·zone 생성 가능. **우리 dye 의 다음 단계.**

## C. 추출 후보 — 中 / 실험적

- **아이템 스탯(공격/방어/인챈트) hover 편집** — 참고 모드 Item Stats. 값은 x1000
  스케일. 우리 인벤토리 뷰에 편집 붙이기.
- **Max Trust (사람·펫)** — 대상에게 인사/선물/쓰다듬기 2회. **말(horse)은 거부**
  (게임이 그 코드 중간으로 분기해 위험 → 참고 모드도 제거).
- **Instant Win (미니게임)** — 카운터를 목표−1 로만 park. ⚠ 그 코드가 지역 내
  모든 스크립트 트리거 카운터와 공유라 문·컷신 오작동 전례. "그럴듯한 스코어보드"
  가 아니면 거부하고 절대 낮추지 않게. 위험 대비 가치 낮음.

## 권장 순서 (내 추천)

1. **라이브 염색 업그레이드(B-10)** — 방금 넣은 염색의 자연스러운 완성. 재장착
   없이 즉시 + 없는 zone 생성. 우리만의 강점(인프로세스) 활용.
2. **Max Refine 일괄(B-9)** — equip 에디터에 버튼 하나. 값싼 고효용.
3. **내구도(B-6)** — Keep@100 / Repair. 실사용 빈도 높음.
4. **플레이어 치트 그룹(B-1)** — Godmode·무한 자원. 단 본인 제한·캐릭터별 슬롯
   주의(참고 모드 실수 목록을 그대로 회피).
5. 이후 탈것(B-2)·시간(B-3)·텔레포트(B-5)·가방(B-7).

각 항목은 별도 spec 으로 리버스 근거를 박은 뒤 착수한다(메모리 직접 쓰기 위험).
